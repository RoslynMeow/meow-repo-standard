## Project mode

- **Issues are the source of truth.** The Project is only a view over Issues.
- Items are real Issues; pull requests are never added.
- Status: `Todo` / `In Progress` / `Done` / `Deferred` / `Canceled`.
- `Start` = Issue creation date; `End` = Issue close date.
- `Area` and `Kind` describe the work.
- `deferred` / `canceled` labels mark paused or abandoned work.
- Views: `All Issues`, `Board`, `Roadmap`, `Canceled`, `Deferred`.
